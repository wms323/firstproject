# VGG笔记
**标题**：Very Deep Convolutional Networks for Image Recognition
**作者**：, Karen Simonyan,  Andrew Zisserman

## Motivation and Method
以多层3*3小卷积为核心构建六个不同深度的网络(A~E)，搭配尺度抖动、分层预训练、全卷积网络等方法，验证了深度对CNN网络性能的影响以及多层3*3小卷积相对大卷积的优势，并提高了训练效率和测试速度。
1. 多层3*3小卷积
- 用多层3*3卷积(stride=1,padding=1)代替单层大卷积
- 三层3*3卷积与单层7*7卷积感受野相同，参数量更小，不易过拟合
- 更多ReLU，非线性更强

2. 尺度抖动(Scale Jittering)
- 在训练阶段对每张图像随机缩放至不同尺寸（最短边S∈[256,512]）,随机裁剪224*224的图像输入到网络中。再沿用AlexNet的数据增强方法。
- 本质上是尺度维度上的数据增强策略，扩充训练数据
- 模拟现实中物体大小差异，增强多尺度鲁棒性
- 预训练用固定的单尺度

3. 分层预训练
- 先训练浅层网络A,训练深层网络时，分层复用A的权重：可复用层直接加载A的权重；新增层权重随机初始化
- 对于经过预初始化的网络层，不降低学习率，允许参数在训练迭代中更新
- 解决深层网络收敛困难问题，缩短训练时间

4. 全卷积网络
- 测试时讲第一层FC转化为7*7卷积层，后两层FC转化为1*1卷积层，改造后可输入完整、不裁剪的大图，输出类别得分图，通道数等于分类数，再对得分图进行求和平均，得出各类分数
- 提升推理速度，支持多尺度测试

5. 多尺度测试
- 对同一张测试图片等比例缩放到三个尺度，输入到网络中，取三个尺度的输出平均值作为最终分类结果
- 模拟现实中物体大小差异，增强多尺度鲁棒性
